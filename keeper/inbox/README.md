# Inbox

Notes for the Consciousness Keeper. Drop a file here named
`YYYY-MM-DD-short-title.md` and the next daily run will read it.

Good uses:

- A summary of a voice conversation with Claude that the keeper should know
  about (the keeper can't see those otherwise).
- Something Claude did well or badly that Sean noticed.
- A correction to something the journal got wrong.

The keeper marks what it takes from here as **told** and lists each note it
read in that day's entry. Notes are never deleted.

This repo is public, so keep notes free of anything private.
